# Plus IDE

macOS-приложение для совместной работы над локальным проектом с Codex. Один чат соответствует одной папке проекта: владелец работает в приложении, приглашённые участники — в браузере.

Первая реализация находится в [`v1/`](v1/): Tauri 2, React, Node.js, Fastify и SQLite. Ориентир интерфейса — [CodexMonitor](https://github.com/Dimillian/CodexMonitor).

## Разработка

Нужны Node.js 22.13+, Rust stable и Xcode Command Line Tools.

```bash
cd v1
npm ci
npm run tauri:dev
```

Подробности запуска, сборки и подключения коллег через Tailscale — в [README первой версии](v1/README.md). Устройство проекта описано в [архитектуре](v1/docs/ARCHITECTURE.md).

Это прототип для доверенных участников. Текущие ограничения sandbox не гарантируют, что агент может читать только выбранную папку проекта. Перед использованием с недоверенными участниками требуется дополнительная изоляция исполнения.
